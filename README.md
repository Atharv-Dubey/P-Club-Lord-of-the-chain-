# P-Club-Lord-of-the-chain-
A command-line simulation of a food delivery service implementing Object-Oriented Programming principles.
Features

Customer Interface: Browse restaurants, place normal or priority orders, track order status
Restaurant Interface: View and manage orders, accept/reject orders, mark orders ready
Delivery System: Assigns nearest available agents with priority queue management
Order Lifecycle: Orders progress through statuses (Initiated → Accepted → Ready → Out for Delivery → Delivered)
Dynamic Pricing: Distance-based delivery fee, priority surcharge, platform fee (7%), GST (5%)
Real-time Updates: Status changes displayed as they occur

To Do's

As restaurant: Accept order, mark as ready when prepared
Use System Status to monitor agents and pending orders
